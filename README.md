# Pokopia Database
![Github latest downloads](https://img.shields.io/github/downloads/Ruimusume/Pokopia/total.svg)

This is a complete item IDs for Pokopia. Currently it can only be run on the [Eden](https://git.eden-emu.dev/Takoroka/eden-nx2/releases). You can use [Cheat Engine](https://www.cheatengine.org/downloads.php) to search for and locate the existing items and quantities in the game to modify them.

For example, for `Leppa Berry`, select an 8-byte search for the Value + `Leppa Berry`ID=`00000924` in HEX to locate it: `0000001D00000924`.

Usually, the last result is the valid address.
