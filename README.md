# Pokopia Database
This is a complete item dataset for Pokopia. Currently it can only be run on the Eden emulator. You can use Cheat Engine to search for and locate the existing items and quantities in the game to modify them.

For example, for "Leppa Berry", select an 8-byte search for the quantity + ID in HEX to locate it: 0000001D00000924.

Usually, the second-to-last result is the valid address.
